# Component attributions

Every component imported from the [21st.dev](https://21st.dev) registry is
recorded here on import: source URL, author, and license.

This is not bookkeeping. Arbor is AGPL-3.0, and a component whose provenance
cannot be established is one a downstream adopter cannot safely ship. Add the
row in the same PR that adds the component.
